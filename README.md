# Amaan Khan — Portfolio

Interactive 3D personal site based on [mohitvirli/mohitvirli.github.io](https://github.com/mohitvirli/mohitvirli.github.io).

## Tech Stack

- Next.js
- React Three Fiber / Drei
- GSAP
- Zustand
- Tailwind

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

Personal content lives mainly in:

- `app/constants/projects.ts`
- `app/constants/work.ts`
- `app/constants/footer.ts`
- `app/components/hero/`
- `app/layout.tsx`
- `public/Amaan-Khan-Resume.pdf`
